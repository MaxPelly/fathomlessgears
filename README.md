# Fathomless Gears

> [!WARNING]
> **Alpha release.** `2.0.0-alpha1` is the first Foundry v13/v14-compatible release of this system. It hasn't been tested against a live Foundry client yet (see below) - expect rough edges, and please report anything broken. If you're still running Foundry v12, stay on the `1.1.0-rc3` release instead.

> [!IMPORTANT]
> **This system's Foundry v13/v14 compatibility update - including this readme - was implemented by an AI coding agent (Claude Code), not a human contributor.** Every change was reviewed step-by-step and checked against Foundry's real API documentation as work progressed, but **no live Foundry client was available to actually run the system during development**, so nothing here has been smoke-tested in a real game yet. Please test carefully before relying on it, and report anything unexpected via [Issues](https://github.com/MaxPelly/fathomlessgears/issues). The [Token Action HUD FG](https://github.com/MaxPelly/fvtt-token-action-hud-FG) module bundled with this system underwent the same kind of AI-assisted migration, for the same reason, at the same time.

An in-development Foundry system for Fathomless Gears.

Meant for use with Gearwright for character building.

## Installation Instructions

From Foundry's Systems page, choose Install System and paste the following manifest URL into the box at the bottom:
https://github.com/MaxPelly/fathomlessgears/releases/latest/download/system.json

You can then get updates via the Check for Updates button on the Fathomless Gears listing on the Systems page.
(Keep an eye on Discord for announcements when new versions go live!)
